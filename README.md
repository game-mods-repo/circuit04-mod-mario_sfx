## Установка мода / Installation

### Способ 1: Автоматическая установка через игру
1. Запустите **Circuit 04**.
2. Откройте Главное меню -> **«Моды»** -> вкладка **«Репозиторий»**.
3. Найдите мод **Super Mario 8-Bit SFX Pack** и нажмите кнопку **«Установить»**.

### Способ 2: Ручная установка из ZIP
1. Скачайте архив `mario_sfx.zip` из последнего [Релиза](https://github.com/game-mods-repo/circuit04-mod-mario_sfx/releases/latest).
2. Поместите архив или распакованную папку в директорию `mods/` (или `mods/maps/` для карт).
3. В игре во вкладке «Менеджер модов» нажмите кнопку **«Обновить список»**.
